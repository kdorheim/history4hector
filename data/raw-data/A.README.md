Due to their size raw-data files may be stored elsewhere see raw-data.urls.txt for
the list of files that need to be downloaded and unzipped. The easiest way to do 
this is probably by running the A2.get-raw-data.sh script. This only needs to be run once! 

All of the files appended with the prefix A are files that are committed to the repository. 

```
sh A2.get-raw-data.sh
```

The CMIP7 GHG concentrations are committed directly to this repository, 
the original netcdf files are available at [ESGF](https://aims2.llnl.gov/search?project=input4MIPs&versionType=all&activeFacets=%7B%22source_id%22%3A%22CR-CMIP-1-0-0%22%7D)
